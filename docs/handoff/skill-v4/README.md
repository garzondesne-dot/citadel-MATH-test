# 🎆 #99 스킬 띠 v4 (새 안 · 비교용 · 게임에는 아직 안 넣음)

- 만든 곳: `tools/fxbake/sk4/` (python3 · numpy · PIL) — `python3 tools/fxbake/sk4/bake.py [이름 …]` 로 다시 굽기
- 옛 띠(public/art/pfx · pfx2)는 지우거나 덮어쓰지 않음 · 새 파일 이름 `sk4-<스킬>-<a|b>-v1.webp`
- `alt.json` = { "sk-<키>": [ { src, w, h, n, cols, fps, px, py, pk, name } ] } · src 는 skill-v4/ 부터
  - px · py = 띠 칸 안 맞는 점(몬스터 가운데) · pk = 맞는 칸 번호(데미지 · 흔들림 시작) · 띠 1줄(cols = n)
- `compare.webp` = 지금 띠(빨강 글자) ↔ 새 안(초록 글자) 9칸씩 나란히

| 키 | 새 안 |
|---|---|
| slash | a 칼끝이 선을 따라 달리고 금이 벌어지며 불꽃 · b 휘두름 궤적 + 벌어지는 틈 |
| twin | x (📜 #109 다시) 화면을 거의 가로지르는 큰 초승달 ↘ → 0.12초 뒤 ↙ = X · 겹칠 때 하얀 번쩍 + 작은 흔들림 · X 잔상 → 흩어짐 (옛 a · b 는 지움) |
| cyclone | a 큰 깔때기 + 튀어나가는 바람 칼날 + 파편 |
| pillar | mix (📜 #110 기존 + 새 섞기) 기존 큰 기둥 띠 그대로 + 옆 기둥 4개 먼저 → 큰 기둥 뒤 불덩이 폭발 → 연기 (옛 a 지움) |
| thunder | mix (📜 #110 기존 + 새 섞기) 기존 큰 번개 · 돔 띠 그대로 + 꽂힌 뒤 양옆으로 연쇄 번개(끝에서 위로 튀는 가지) → 퍼진 자리마다 지지직 잔향 (옛 a · b 지움) |
| vortex | a 나선 팔 5개 크게 → 조여 → 빛 폭발 |
| void | a 블랙홀(원반 · 광자 고리 · 빨려 드는 알갱이) · b 같은 블랙홀 + 위아래 제트 |
| wave | a 말리는 큰 파도 → 물보라 · b 물결 3겹 → 큰 물보라 |
| tsunami | a 물 칼날 X → 거대 해일 → 물보라 3번 · b 물 소용돌이 → 내려 벰 → 양옆 해일 |
